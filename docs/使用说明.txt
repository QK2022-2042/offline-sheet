离线协同表格 · 使用说明（绿色版，目标机无需安装任何东西）
================================================================

【这是什么】
断网局域网里多人共同填写表格/表单的工具。上传人把 Excel(.xlsx) 或
Word 表单(.docx) 导入成网页，大家同时在线填写，最后只有上传人能
导出文件——导出件回写到原模板，格式和内容与原文件一致。

【怎么启动】（在上传人的电脑上）
1. 把整个 offline-sheet 文件夹拷到任意位置（如 D:\offline-sheet）
2. （可选，仅首次）右键"防火墙放行.bat"→ 以管理员身份运行
3. 双击 start.bat，窗口里会显示局域网地址，例如：
      局域网访问 http://192.168.0.50:8081
4. 把这个地址发到科室群，大家用浏览器（Chrome/Edge）打开

【角色规则】
- 第一个输入名字进入的人 = 上传人：可导入、可导出
- 其他人 = 协作者：只能在线填写，导出按钮不可见，接口直接 403
- 上传人 = 第一位进入者，如需更换上传人：删除 data 文件夹后重启

【使用流程】
1. 上传人打开网页 → 输入姓名 → 点"导入 Excel / Word"选文件
2. 大家各自填写，改动实时同步（别人的格子会闪动提示）
3. 定稿后上传人点"导出 Excel"或"导出 Word"下载到本机

【换端口】
在 offline-sheet 文件夹里新建 port.txt，写一个端口号（如 8081），
重新双击 start.bat 即可。

【数据在哪】
所有填写内容存在 data\doc.json，原始模板存在 data\template.xlsx
或 template.docx。备份 = 拷走整个 data 文件夹。

【重要边界（务必知道）】
- Excel 导出：公式、样式、列宽、条件格式保留；图表和图片
  （openpyxl 限制）不保留
- Word 仅支持"表格型表单"：正文段落不会出现在网页里，导出时
  正文原样保留；表格内新增行无法回写到模板（模板里没有该行）
- 并发策略：同一格两人同时改，后提交者覆盖
- 建议单表 ≤ 2000 行 × 40 列
- "禁止下载"靠服务端拦截 + 页面水印，防不了截屏拍照

【常见问题】
- 同事打不开网页 → 检查防火墙放行 8081 端口；确认双方在同一局域网
- 端口被占用 → 换端口（见上）
- 内容丢了 → 查看 data\doc.json 是否存在；填写内容每 5 次修改落盘
